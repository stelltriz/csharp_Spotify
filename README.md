## Basic Spotify (C#) 🎵
A simple music management app inspired by Spotify, built with C#.
Add artists, songs, view tracks, and rate them.

### Features ✨
- Add artists
- Add songs to artists
- View songs by artist
- Rate songs

### Technologies Used 🛠
- C#
- .NET 8

### How to Run ▶️
- Clone the repo
- Open in Visual Studio
- Build and run
